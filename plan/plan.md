# 2. 홈페이지의 목적

오늘사회적협동조합 홈페이지는 단순히 기관의 정보를 제공하는 홈페이지가 아니라,

**오늘사회적협동조합이 어떤 철학을 가지고 사람을 만나고,
어떤 사회를 만들어가고자 하는지를 보여주는 브랜드 홈페이지**를 목표로 한다.

특히 동구발달장애인 주간활동서비스센터 오늘의 서비스와 활동을 통해

* 발달장애인을 한 사람의 존엄한 삶의 주체로 바라본다는 것
* 자신의 삶을 스스로 선택하고 결정할 수 있도록 지원한다는 것
* 돌봄을 넘어 성장과 자립으로 연결한다는 것
* 지역사회 안에서 함께 살아가는 삶을 지향한다는 것

을 자연스럽게 전달한다.

# 19. TODAY — 설립목적

## 우리의 설립목적

오늘사회적협동조합은
장애인을 보호와 시혜의 대상으로 바라보지 않습니다.

* 지역사회 안에서 함께 살아갈 수 있는 관계와 환경을 만듭니다.

우리가 만들고 싶은 것은
누군가를 대신 살아주는 삶이 아니라,

> **한 사람이 자신의 삶을 살아갈 수 있는 사회입니다.**
